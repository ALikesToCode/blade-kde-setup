# Where to look

Open these in a browser when you need them. Stop at logins and paywalls. Learn the principle and
build your own; licences and terms differ and several forbid redistributing their content.

## Finished work to learn from

| Source | Good for |
| --- | --- |
| https://www.awwwards.com/websites/sites_of_the_day/ | Real shipped sites filtered by technique, font or colour, with clips of single interactions |
| https://www.hoverstat.es/ | Short captures of unusual interactions on live studio sites, with a note on the mechanic |
| https://motionsites.ai/ | Hero and page designs paired with very detailed build prompts. Study how much they decide in advance: assets, crops, fonts, timings, breakpoints, fallbacks |
| https://recent.design/ | Recent sites tagged by stack |

Several galleries answer a headless browser with a bot check, among them landing.love, land-book.com
and lapa.ninja. Do not work around it. Ask the owner for a capture, or pick another source.

## How an effect is made

| Source | Good for |
| --- | --- |
| https://tympanus.net/codrops/ | Tutorials and case studies with demos and code. The site blocks headless browsers |
| https://github.com/codrops | The same demos as runnable source, one effect per repository, with credits and a licence in each README |
| https://github.com/darkroomengineering/satus | A studio's starter whose `AGENTS.md` holds its motion and WebGL rules: CSS entrances, sticky pinning, WebGL after load, a DOM fallback for every scene |
| https://basement.studio/blog | A studio's write-ups on GSAP with Next.js, shaders and 3D pipelines |
| https://blog.maximeheckel.com/ | Shader and WebGPU techniques explained step by step |

## Parts to drop into a React and Tailwind project

| Source | Good for |
| --- | --- |
| https://reactbits.dev/ | Animated text, backgrounds and shader components with live controls; installs through the shadcn registry |
| https://21st.dev/ | A large component catalogue with copyable prompts and a registry. Many entries look like stock SaaS; pick parts, not pages |
| https://magicui.design/ | Effects and animated primitives with documented props |
| https://shaders.paper.design/ | Shader backgrounds as components |
| https://www.unicorn.studio/ | A WebGL scene editor with an embed runtime |

A page assembled from catalogue parts inherits the catalogue's look. Use one part where it serves
the thesis.

## Measuring whether a page is better

| Source | Good for |
| --- | --- |
| https://www.designarena.ai/about | The method to copy when comparing two builds: the same brief for both, shown in unnamed pairs, a person picks one, and wins are counted. A score from one judge on one page proves little |

| Source | Good for |

## Other skills on this machine

Use these alongside this skill rather than repeating them: `frontend-design-director` (general
interface work; when it already leads a task it stays the lead and borrows this skill's asset step,
beat step and capture scripts), `impeccable` (critique, audit, polish and its detector), `improve-animations` and `find-animation-opportunities` (motion in an existing
codebase), `animation-vocabulary` (naming an effect), `make-interfaces-feel-better` (small details),
`accessibility`, and `local-media` (the `lmedia` tools).
